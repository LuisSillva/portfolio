# Currículo

`curriculo.html` é a fonte do `public/curriculo.pdf`.

Para gerar o PDF depois de editar:

1. Rode `npm install` na raiz do projeto (instala as fontes Inter e JetBrains Mono).
2. Abra `cv/curriculo.html` no Chrome.
3. Ctrl+P, destino **Salvar como PDF**, margens **Nenhuma**, com **Gráficos de plano de fundo** marcado.
4. Salve por cima de `public/curriculo.pdf`.

O texto precisa caber em uma página A4. Se passar, o Chrome cria uma segunda página.
